## Goal  
Replace one word with another word inside a text file using Python.

---

## Files
| File Name | Description |
|------------|--------------|
| `01_word_replace.py` | Basic version – replace word in a text variable (in-memory). |
| `02_word_replace.py` | Modular version – read from a file, replace, and save. |
| `03_word_replace.py` | Final version – professional file replacer with count display. |
| `output.txt` | Example text file used for testing word replacement. |
| `project.yml` | Metadata file for tracking project details. |

---

## How It Works
1. The script opens a file and reads its content.  
2. User enters the word to find and the new word to replace it with.  
3. All occurrences are replaced and saved back to the file.  
4. The program shows how many replacements were made.
